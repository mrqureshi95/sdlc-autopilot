A practical workflow for coding agents: understand the scope, fix the cause, add useful protection, and show what was actually verified.

01 / Choose the task

Review → inspect and report.

Implement → change and verify.

Deploy → prepare the exact operation
and use the authority actually given.

02 / Scale to the risk

Quick

Cosmetic or isolated disposable work.
Small, relevant checks.

Standard

Bugs, features and refactors.
Behavior and compatibility evidence.

Full

Security, data, contracts or delivery risk.
Targeted threat and recovery review.

Risk follows impact and reversibility. File count and “quickly” do not set the mode.

03 / Fix–Guard–Test–Verify

01 / Cause

Fix

Reproduce where practical. Use the canonical contract and the smallest safe change.

02 / Prevention

Guard

Add a useful type, rule, invariant or regression. Inspect related causes in context.

03 / Behavior

Test

Match evidence to the task: regression, characterization, contract, rehearsal or benchmark.

04 / Evidence

Verify

Run relevant checks. Review the diff, boundaries and final state. Report residual risk.

04 / Know what was verified

Pass

The stated, scoped check was satisfied.

Fail

A check failed. Inspect its cause and consequence.

Inconclusive

Evidence is missing or unsupported. Say what remains unknown.

Not applicable

The check does not apply. No pass credit is implied.

Protect the work

Preserve user edits. Track the starting state and affected projects. Triage unrelated findings; keep scope tight.

Keep execution deliberate

Inspect configured commands. No implicit package downloads or repository-wide fixes. External review and deployment need specific authority.

Hand off something useful

Explain the change, actual checks, gaps and next action. A read-only audit needs no patch. Already authorized work need not pause again.

The boundary: a skill guides decisions; CI, repository checks, permissions and independent review provide enforcement. Local test results do not prove security or every agent’s behavior.
